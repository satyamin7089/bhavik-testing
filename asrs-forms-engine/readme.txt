Enterprise-grade, developer-first WordPress form management platform with PHP-registered forms, AJAX submissions, draft recovery, abandoned form tracking, and Zoho CRM API v7 integration.

== Description ==

ASRS Forms Engine is a code-first WordPress forms platform built for agencies and engineering teams. Forms are authored in clean OOP PHP and automatically exposed via shortcodes, backed by local WordPress database tables, draft auto-save/recovery, WP-Cron retry queues, and full Zoho CRM API v7 integration.

== Shortcodes ==

* `[asrs_form id="contact-product-enquiry"]`
* `[asrs_form_contact_product_enquiry]`
